error! if this message is on screen, the game broke somehow.

this can be because of a variety of reasons:
  • your browser is still loading this page
  • you are running this index.html without any of the assets in the same folder
  • you downloaded a zip of this game but didn't extract it to a folder
  • you have javascript disabled on your browser
  • your browser is too old to run the javascript (lookin at you ie 11)
  • the javascript file is corrupted
  • there is a bug in the code
in any case, try running the game with the files and asset folder all in one folder
(and redownload/re-extract the files if needed)
that is, you should be able to see in your file explorer:
  1. assets (folder)
  2. index.html
  3. main.js
  4. style.css
